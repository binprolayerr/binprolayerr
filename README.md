### 🤖 AI for Security
- 🧠 **Vulnerability Detection**: detecting vulnerabilities in C source code with deep learning
- 🏷️ **Multi-label CWE Classification**: classifying multiple vulnerability types (CWE) per code sample
- 🌐 **Federated Learning**: decentralized model training that keeps source code private
- 🔬 **Transformer-based Models**: representing and analyzing source code
- ⚖️ **Imbalanced Data Handling**: addressing class imbalance with SMOTE and sampling techniques
